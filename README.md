# Bramblewatch beta

A tiny mouse homestead, living plants, and a forest full of trouble.

Play: https://edianibarrola.github.io/bramblewatch/

## Controls

- Laptop: WASD or arrow keys to move; click plots/buildings or press E nearby.
- Phone: play in landscape; drag anywhere to move and tap to interact.
- Weapons fire automatically. Prepare your farm, then ring the night bell.

Progress is saved locally in your browser. Each browser profile/device has a separate farm. Clearing site data removes its save. There are no accounts or cloud saves.

This repository contains the compiled browser game only, not the Unity source project. This is a beta: balance and save compatibility may change.
